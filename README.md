#  Clean Street  

###  A Smart Civic Issue Reporting Platform  

*Clean Street* is a web-based application built using the *MERN Stack* that helps citizens easily *report civic issues* like garbage, potholes, and streetlight failures.  
It connects *citizens, volunteers, and administrators* to ensure issues are resolved efficiently and transparently.

## Tech Stack  

Layer -> Technology 
💻 Frontend -> React.js 
⚙ Backend -> Node.js + Express.js 
🗄 Database -> MongoDB 
🔐 Authentication -> JWT + bcrypt 
🗺 Map Integration -> React-Leaflet 
📊 Charts & Analytics -> Recharts 
📧 Email OTP -> Nodemailer 
🖼 File Uploads -> Multer 


## ✨ Key Features  

-  *Report Issues:* Citizens can report problems with descriptions, images, and location.  
-  *Interactive Map:* Issues appear on a live map using *React-Leaflet*.  
-  *Comments & Votes:* Citizens can comment or upvote to support community concerns.  
-  *Secure Authentication:* JWT-based login and registration.  
-  *Forgot Password:* Email-based OTP verification for password reset.  
-  *Role-Based Dashboards:* Separate dashboards for Citizens, Volunteers, and Admins.  
-  *Analytics:* Admins can track progress and generate reports.
